# Product artwork

`llamadock-app-icon-source.png` is the source artwork used to derive the macOS
AppIcon asset set. It was generated with the built-in image generation tool
for this project and contains no third-party logo or stock asset.

Final prompt:

> Create a premium native macOS app icon for LlamaDock that combines a friendly
> geometric llama head with a subtle terminal and dock motif. Use a deep indigo
> and midnight navy base, teal/cyan accents, and a small coral highlight. Keep
> a bold, centered, simple silhouette that remains clear at 16 px. Use smooth
> enamel and subtle brushed-metal materials. Include no text, letters, numbers,
> watermark, Apple logo, GitHub logo, OpenAI logo, third-party marks, device
> mockup, or surrounding scene.
